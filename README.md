# 📝 Minha Lista de Tarefas

Aplicação de lista de tarefas (To-Do List) desenvolvida como atividade prática de introdução ao React.

## 🚀 Tecnologias utilizadas
- **React** — biblioteca JavaScript para construção de interfaces
- **Vite** — ferramenta de build rápida para projetos React
- **JSX** — sintaxe que combina HTML e JavaScript dentro do React
- **CSS** — estilização personalizada da interface

## ✅ Funcionalidades
- Adicionar novas tarefas
- Marcar tarefas como concluídas com checkbox
- Remover tarefas individualmente
- Limpar todas as tarefas concluídas de uma vez
- Contador de tarefas pendentes e concluídas

## 🧠 Conceitos aprendidos
- **JSX** — permite escrever HTML dentro do JavaScript de forma simples
- **Componentes** — cada parte da tela é um componente reutilizável (ex: TarefaItem)
- **Props** — forma de passar informações entre componentes
- **useState** — hook do React que guarda e atualiza dados na tela em tempo real
- **map()** — percorre a lista de tarefas para exibi-las na tela
- **filter()** — remove tarefas da lista sem apagar as outras

## 📦 Como rodar o projeto
npm install
npm run dev

Acesse: http://localhost:5173
